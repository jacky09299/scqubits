2. scqubits 是否會在內部自動乘以 (C_c / C_\sigma)^2 之程式碼分析說明
--------------------------------------------------------------------------------
根據 scqubits 原始碼分析（參見 scqubits/core/noise.py 第 1438-1450 行）：

def t1_charge_impedance(..., Z=NOISE_PARAMS["R_0"], ...):
    Z_fun = Z if callable(Z) else lambda omega: Z

    def spectral_density(omega, T):
        Q_c = CONSTANTS["R_k"] / (8 * np.pi * complex(Z_fun(omega)).real)
        ...

結論：
scqubits 本身的 t1_charge_impedance() 方法**【不會】**在內部自動乘以 (C_c / C_\sigma)^2 縮放因子！

相反地，scqubits 的設計要求使用者在傳入 Z 參數時，傳入「量子位元端所感受到的有效等效阻抗」Z_{eff}(\omega)。
因此，若外部系統透過耦合電容 C_c 耦合至線路阻抗 Z(\omega)，使用者必須自行將縮放因子 (C_c / C_\sigma)^2 包含在傳入的 Z 或 Z(\omega) 函數中。

3. 環境阻抗 Re[Z(\omega)] 計算公式 (Environmental Impedance Formulas)
--------------------------------------------------------------------------------
在 scqubits 中，t1_charge_impedance(Z=...) 的 Z 參數代表量子位元端感受到的有效等效阻抗 Re[Z_{eff}(\omega)]。
根據 Cattaneo et al. (2021) 論文，針對不同的電路環境，Re[Z_{eff}(\omega)] 的計算公式如下：

(1) 傳輸線環境 (Transmission Line):
    Re[Z_{eff}(\omega)] = (C_c / C_\sigma)^2 * Z_0
    其中：
    - C_c 為量子位元與傳輸線之間的耦合電容 (Coupling Capacitance)
    - C_sigma = e^2 / (2 * E_C) 為量子位元總電容 (Total Qubit Capacitance)
    - Z_0 為傳輸線特徵阻抗 (典型為 50 Ohm)

(2) 多級帶通濾波器環境 (Multi-stage BPF):
    Re[Z_{eff}(\omega)] = (C_c / C_\sigma)^2 * Z_{bpf}(\omega)

    其中 Z_{bpf}(\omega) 由濾波器模式的局部狀態密度 (Local Density of States, LDOS) 決定：

    a. 建構 N 階濾波器的 N x N 耦合矩陣 M:
       M_{j, j} = -i * \omega_0 - \kappa_j / 2
       M_{j, j+1} = M_{j+1, j} = -i * c_j
       其中：
       - \omega_0 = 2 * \pi * f_{filter} 為濾波器中心角頻率
       - dw = 2 * \pi * BW 為濾波器頻寬 (Rad/s)
       - \kappa_0 = dw / g_0g_1, \kappa_{N-1} = dw / g_{N-1}g_N 為兩端耗散率
       - c_j = dw / (2 * \sqrt{g_j g_{j+1}}) 為級間耦合強度

    b. 計算格林函數 (Green's Function) 反矩陣：
       G(\omega) = (i * \omega * I + M)^{-1}

    c. 提取指定耦合級次 (k_stage) 的局部狀態密度 (LDOS):
       \rho_k(\omega) = -\frac{1}{\pi} Re[ G(\omega)_{k, k} ]

    d. 以中心頻率 \omega_0 正規化至 50 Ohm 傳輸線阻抗 Z_0：
       Z_{bpf}(\omega) = Z_0 * \frac{\rho_k(\omega)}{\rho_k(\omega_0)}

傳遞給 scqubits 時：
- 傳輸線：直接傳入純量 Z = (C_c / C_\sigma)^2 * Z_0
- 多級 BPF：傳入可調用函數 Z = lambda \omega: (C_c / C_\sigma)^2 * Z_{bpf}(\omega * 10^9)
  （注意：scqubits 傳給 Z(\omega) 的角頻率單位為 2*\pi*GHz，需乘以 10^9 換算為 rad/s）


--------------------------------------------------------------------------------
4. scqubits 核心數學公式 (scqubits Noise Formulas)
--------------------------------------------------------------------------------

(A) 躍遷角頻率 \omega_{ij}:
    \omega_{ij} = 2 * \pi * (E_i - E_j)
    其中 E_i, E_j 為量子位元在系統單位 (預設為 GHz) 下的特徵能量。
    當計算衰減 (i > j, 如 3->0) 時, \omega_{ij} > 0;
    當計算激發 (i < j, 如 0->3) 時, \omega_{ij} < 0。

(B) 等效品質因子 Q_c (微觀阻抗參數化):
    位於 noise.py 第 1441 行：
    Q_c = R_k / (8 * \pi * Re[Z_{eff}(\omega_{ij})])
    其中 R_k = h / e^2 為 von Klitzing 常數，Re[Z_{eff}(\omega)] 為環境實部阻抗 (Ohm)。

(C) 電壓噪聲功率譜密度 S(\omega):
    位於 noise.py 第 1442-1449 行：
    S(\omega) = \frac{2 \omega}{Q_c} * \frac{1}{\tanh(0.5 * \beta \omega)} * \frac{1}{1 + e^{-\beta \omega}}

    透過恆等式 \frac{1}{\tanh(x/2)} = \frac{1 + e^{-x}}{1 - e^{-x}}，公式可簡化為標準熱噪聲形式：
    S(\omega) = \frac{2 \omega}{Q_c} * \frac{1}{1 - e^{-\beta \omega}}
              = \frac{16 \pi \cdot Re[Z_{eff}(\omega)] \cdot \omega}{R_k} * \frac{1}{1 - e^{-\hbar \omega / (k_B T)}}

(D) 費米黃金律 (Fermi's Golden Rule) 躍遷率 \Gamma_{i \to j}:
    位於 noise.py 第 1261-1275 行：
    \Gamma_{i \to j} = |\langle i | n | j \rangle|^2 * S(\omega_{ij})

    其中：
    - n 為電荷算符 n = Q / (2e) (即 fl.n_operator())
    - \langle i | n | j \rangle 為能級 i 到 j 的電荷算符矩陣元素
    - 當設定 total=False 且 get_rate=True 時，回傳單向躍遷率 \Gamma_{i \to j}

(E) 單位轉換 (Units):
    scqubits 回傳的 rate 單位為系統頻率單位 (GHz)。
    若要換算為 MHz，需乘以 10^3 (即 1 GHz = 1000 MHz)。


--------------------------------------------------------------------------------
5. 與原作者 (Cattaneo 2021) 公式之物理等價性說明
--------------------------------------------------------------------------------
在 fluxonium_bpf.py 中，使用的公式為：
\Gamma_{i \to j} = (2e / hbar)^2 * |\langle i | n | j \rangle|^2 * S_{VV}(\omega_{ij})
其中 S_{VV}(\omega) = \frac{2 \hbar \omega}{1 - e^{-\hbar \omega / (k_B T)}} * Re[Z_{eff}(\omega)]

代入 (2e / hbar)^2 * S_{VV}(\omega)：
(2e / hbar)^2 * 2 \hbar \omega * Re[Z_{eff}(\omega)] = \frac{8 e^2 \omega}{\hbar} * Re[Z_{eff}(\omega)]
                                                      = \frac{16 \pi e^2 \omega}{h} * Re[Z_{eff}(\omega)]
                                                      = \frac{16 \pi Re[Z_{eff}(\omega)] \omega}{R_k}

與 scqubits 的 S(\omega) 完全一模一樣！因此兩者物理結果在機器精度範圍內完全吻合。
